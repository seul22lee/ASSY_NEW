# evaluator_only/

Material that must **not** reach a Demonstration CAD author.

The Demonstration author's entire permitted input is
`../source_only_packet/`. Everything here is for the independent evaluator who
assesses a demonstration after it has been authored: the packet manifest, the
source-silence analysis, and any pointer into the semantic Oracle.

Reading anything here before or during Demonstration authoring contaminates the
run. That is not a formality — the whole value of a source-only demonstration is
that it was produced without knowing what would be checked.
