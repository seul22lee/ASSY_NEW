# Source precedence

Rank 1 is the only rank that defines correctness for this task.

| Rank | What it is | Can it define correctness? |
|---|---|---|
| 1 | explicit product intent and benchmark requirements | **yes** |
| 2 | explicit engineering review findings | no |
| 3 | verified evidence | no |
| 4 | reference realizations | no |
| 5 | historical examples | no |
| 6 | legacy implementation behaviour | **never** |

You have been given rank-1 material only.

If you find yourself reasoning "a box like this usually has X", stop. That is not
rank 1. Either the source requires X or you are free to choose it, and which of
those is true must be visible in what you produce.
